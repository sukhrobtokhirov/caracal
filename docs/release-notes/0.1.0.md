Caracal is a free desktop IDE for Postgres and Redis: one native window where both
engines sit side by side, with a schema browser and SQL editor for PostgreSQL and a
key browser, value viewers, and a guarded command console for Redis. Everything is
local — no account, no telemetry, no network listener, and no JDK to install.

This is the first public release. It is v0.1: deliberately narrow, read-first, and
honest about what it has not been through yet.

## Platforms

| Platform | File |
|---|---|
| macOS 13+ (Apple Silicon) | `caracal_0.1.0_macos_arm64.dmg` |
| macOS 13+ (Intel) | `caracal_0.1.0_macos_x86_64.dmg` |
| Linux x86-64 (glibc 2.39+) | `caracal_0.1.0_linux_x86_64.deb` |
| Linux ARM64 (glibc 2.39+) | `caracal_0.1.0_linux_arm64.deb` |
| Windows 10/11 x86-64 | `caracal_0.1.0_windows_x86_64.msi` |

Each installer is about 100 MB because it carries its own trimmed Java runtime.
Windows on ARM has no native build yet; the x86-64 installer runs under emulation.

## PostgreSQL

- Schema browser, loaded lazily from `pg_catalog`.
- SQL editor with statement splitting, run, and cancel that stops the statement on
  the server.
- A virtualized result grid that keeps `numeric` and `int8` at full precision.
- Errors reported where they happened, with the character the server pointed at
  underlined in the editor.
- CSV export, streamed rather than buffered.

## Redis

- Bounded `SCAN` key browser with prefix grouping, pattern and type filters, and
  pipelined metadata. Never `KEYS`.
- Paged viewers for all six value types, with TTL.
- `INFO` dashboard.
- Command console behind a guard that refuses the commands that stop a server.

## Around both

Query history that is searchable, paged, and reopenable without running anything.
SQL tabs that keep their own connection, query, and result. Keyboard access
throughout, including a connection switcher that will not let Enter dial
production. Light, dark, and system themes.

## Security, in plain language

Your database passwords are encrypted on your machine with a key derived from a
master password you choose on first launch — Argon2id, then AES-256-GCM per
credential. The master password is never stored and **cannot be recovered**: forget
it and the saved passwords are gone.

Connections are read-only until you mark them otherwise, and a write on a
production-tagged connection asks you to type the connection's name. Credentials,
Redis command arguments, and query parameters never reach a log or an error
message. Nothing is sent anywhere.

Full details, and what is out of scope, are in `SECURITY.md`.

## Limitations in 0.1

- **The installers are unsigned.** macOS and Windows will warn on first launch; the
  README documents the exact steps. Verify the checksums first.
- The result grid is read-only.
- Tested against **PostgreSQL 16** and **Redis 7**. Other versions are likely fine
  and untested — please report what you find.
- No Windows ARM build, no cloud sync, no plugins, no AI.

## Install

Download the file for your platform, verify it, and follow the README:

```sh
sha256sum --check --ignore-missing checksums.txt
```

(`shasum -a 256` on macOS; `Get-FileHash <file> -Algorithm SHA256` on Windows.)

Then see [Run it](https://github.com/stohirov/caracal#run-it) for the first-launch
steps on each platform, and [Your first
connection](https://github.com/stohirov/caracal#your-first-connection).

## Reporting

Bugs go to the [issue tracker](https://github.com/stohirov/caracal/issues) — please
redact hostnames, usernames, and query text. Security vulnerabilities go privately
through [`SECURITY.md`](https://github.com/stohirov/caracal/blob/main/SECURITY.md),
never as an issue.
